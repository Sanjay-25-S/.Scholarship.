About ScholarHub

ScholarHub helps students discover scholarships, apply online and keep a record of their applications. Administrators can later review and approve applications.

This is a mini project for Foundations of Full Stack (26CS102).

Technologies used

  • HTML5 (semantic tags)
  • CSS3 (Flexbox, Grid, media queries)
  • JavaScript ES6+ (DOM, events)
  • Fetch API with JSON
  • Git and GitHub
